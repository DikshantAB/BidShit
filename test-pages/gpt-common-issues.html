Open BidShitter DevTools on this page, then click an issue. Every button performs a full page reload with one isolated GPT scenario so the extension can observe setup from boot. The page loads GPT from https://securepubads.g.doubleclick.net/tag/js/gpt.js and uses Google's public sample network only for lifecycle requests.

Testing workflow: keep DevTools open, click one scenario, wait for the relevant boot/network/render threshold, and compare the extension with the page-side event log. Browser extensions, privacy settings, and GAM availability can add environmental failures; reload a scenario before concluding it is nondeterministic.

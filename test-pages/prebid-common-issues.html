Common Prebid issue reproductions

Open BidShitter DevTools on this page, then click an issue. Each button performs a full page reload with one isolated scenario so the extension can observe Prebid from boot. The page uses https://cdn.jsdelivr.net/npm/prebid.js@latest/dist/not-for-prod/prebid.js and the built-in debugging interceptor; it does not call a real bidder endpoint.

Testing workflow: keep DevTools open, click one scenario, wait for the stated timeout/grace period, verify the Issues and Events panels, then select the next scenario. Related summary issues can legitimately appear together, especially PB-07 with PB-11.
